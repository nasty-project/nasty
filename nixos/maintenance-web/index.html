Before making repairs

Check that the intended data pools are unmounted. This page only checks mounted paths under /fs and non-root bcachefs mounts; it does not certify that all disks are safe to repair.

findmnt -rn -t bcachefs

Return to normal operation

When you are finished, run this over SSH or at the console. It explicitly exits maintenance and reboots the NAS.

sudo nasty-maintenance exit

This page will detect the normal dashboard returning after reboot. It cannot exit maintenance or run commands for you.
